

\# 🏦 FINARIUM



\*\*Référentiel unique des instruments financiers\*\*



\## 🎯 Objectif



Centraliser, fiabiliser et gouverner l'ensemble des données relatives aux instruments financiers.



\## 🛠️ Stack technique



\- \*\*Back-end\*\* : Java 17 · Spring Boot 3 · PostgreSQL 15

\- \*\*Front-end\*\* : React 18 · Vite · Material UI

\- \*\*Sécurité\*\* : Keycloak · OAuth2 / OpenID Connect

\- \*\*CI/CD\*\* : Docker · Kubernetes



\## 🚀 Démarrage rapide



\### Prérequis



\- Java 17

\- Node.js 20

\- Docker \& Docker Compose

docker-compose up -d
